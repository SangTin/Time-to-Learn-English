
  

#  Time To Learn English

  

Welcome to the Time To Learn English App! This application is designed to help users enhance their English language skills through various features such as a comprehensive dictionary, Google Translate integration, and interactive English learning games.

  

##  I. Functionality

  

###  1. Learn English with a Dictionary

  

####  Search Words

-  **Explanation:** Obtain detailed explanations for words.

-  **IPA (International Phonetic Alphabet):** View the pronunciation using IPA.

-  **Accent:** Listen to the word pronounced in both British and American accents.

-  **Examples:** Access example sentences and links to related words within the examples.

  

####  Show All Words

- Display the entire dictionary of 100,000 words.

  

###  2. Google Translate Integration

  

####  Translate Text

- Translate text from one language to another. Users can input the source and target languages or enable language detection.

  

####  Speech to Text

- Convert spoken English into text for easy input.

  

####  Text to Speech

- Enter text and hear it spoken in English, aiding pronunciation correction.

  

###  3. English Learning Games

  

####  Cross Game

- Receive explanations or synonyms, then guess the word to complete the table.

  

####  Catch the Word

- View a picture and guess the corresponding English word.

  

##  II. Technologies Used

  

###  1. JavaFX

- The application is designed using JavaFX, providing a user-friendly interface.

  

###  2. Google Translate API

- Utilize the Google Translate API for translation, speech-to-text, and text-to-speech functionalities.

  

###  3. Trie Data Structure

- The dictionary is stored using a Trie data structure.

-  **Advantages:**

- Faster and easier word access.

- Efficient addition and removal of words.

- Complexity calculations are optimized.

  

###  4. MySQL

- Manage and store dictionary data efficiently using the MySQL database.
